# 📱 BMI Calculator App – Feature List

## ✅ Core Features (MVP)
- [x] Calculate BMI based on:
  - Gender selection (Male / Female)
  - Height (via slider)
  - Weight (via counter)
  - Age (via counter)
- [x] Clean UI with support for Light/Dark theme
- [x] Display result:
  - BMI value
  - BMI category (e.g. Normal, Overweight)
